### 🧮 2. [BMI Calculator] — Java Swing + MySQL
> **Type:** Desktop GUI Application (Group Project)  
> **Architecture:** Data Access Object (DAO) Pattern

- **Key Focus:** Object-Oriented Programming (OOP), Database Integration, Clean Code Architecture.
- **Tech Stack:** `Java` `Java Swing` `MySQL` `NetBeans IDE` `DAO Pattern`
- **Source Code:** [📁 Inayasal/BMI-calculator](https://github.com/Inayasal/BMI-calculator)
